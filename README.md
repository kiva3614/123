# 《第七史詩》（Epic Seven／E7）新手詳細攻略

> 適用對象：剛入坑、回鍋後重新整理帳號方向，或不知道資源該先投資在哪裡的玩家。  
> 核心原則：**先建立能穩定推圖、刷討伐的隊伍，再擴充角色池；先求穩定通關，再追求高速與完美裝備。**

> **版本提醒**：E7 的新手活動、免費召喚、兌換商店、角色平衡與活動獎勵會隨版本調整。本文以常駐玩法與通用養成原則為主；限時福利請以遊戲內公告、活動倒數及召喚頁面為準。角色名單與隊伍建議不是唯一解，應依帳號已有角色、裝備及關卡需求調整。

## 一、開局前先做的事

### 1. 綁定帳號

- 先完成遊戲帳號綁定，確認登入方式可用，再投入大量時間。
- 確認伺服器、角色名稱與帳號狀態；跨伺服器、帳號轉移等規則請以遊戲當前說明為準。
- 領取信箱、簽到、新手任務及活動頁面中的可領獎勵。
- 不要因為抽到一隻稀有角色，就忽略帳號綁定與新手任務。

### 2. 先看新手活動

登入後依序查看：

1. 新手簽到與成長任務。
2. 新手專屬召喚或選擇召喚。
3. 月光英雄祝福／月光英雄選擇等新手系統（若帳號目前可使用）。
4. 新手裝備、英雄選擇券、成長支援與任務獎勵。
5. 限時活動與活動商店。

不同版本可能調整任務條件、獎勵及系統名稱。遇到選擇券、月光英雄或稀有成長資源時，先看清楚是否能更換、是否有期限，以及選擇後是否不可逆。

## 二、開局與選擇召喚

### 1. 什麼是選擇召喚？

選擇召喚是新帳號開局的重要機會，可在限定次數內反覆查看一組召喚結果，最後保留其中一組。一般而言，它不是讓你直接選任意角色；實際可抽角色池、次數及操作方式，以遊戲內介面為準。

**挑選原則：先補足隊伍功能，不要只看五星稀有度。**

可優先考慮的方向：

- **伊賽莉亞（Iseria）**：泛用 PvE 輔助，技能重置與破防等效果在不少 PvE 場合有價值。
- **塔瑪林爾（Tamarinne）**：強力 PvE 輔助，但是否能在選擇召喚取得，請確認當前召喚池。
- **維德瑞（Vildred）**：清怪與推圖方向的輸出選項。
- **其他能補足生存、破防或穩定輸出的英雄**：如果免費贈送英雄已經補足某個位置，就不必重複追求相同功能。

角色強度會隨版本與玩法改變。以上是功能方向，不是保證適用所有帳號的固定排名。

### 2. 別把「抽到五星」當成唯一標準

確認結果前，請檢查：

- 這隻角色是否能幫助推主線或通關 PvE？
- 是否已經有免費角色能完成相同工作？
- 同一組結果中的三星、四星角色是否實用？
- 你是否真的理解這個角色的用途？

新手前期最需要的是**能組成隊伍並穩定通關的角色**，而不是只收藏稀有角色。

### 3. 限定、月光與一般召喚

- **一般契約召喚**：主要使用天空石或書籤等資源；具體機率與保底請查看召喚資訊。
- **限定召喚**：通常有指定角色及獨立計數規則，活動結束後不一定能立即取得。
- **神秘召喚**：主要取得當期神秘召喚指定的英雄，保底計數請以當前介面為準。
- **月光召喚**：主要取得光明／黑暗屬性英雄，資源較珍貴。
- **新手選擇、月光祝福及英雄選擇券**：先讀清楚選項與更換限制，不要急著確認。

**抽卡資源建議：** 前期不要因為手上有天空石就全部投入一般召喚。先確認近期限定角色、自己的隊伍缺口，以及活動保底需求，再決定是否抽卡。

## 三、新手推進順序

遊戲會隨帳號進度開放新功能，請以畫面中的解鎖條件為準。大方向可依下列順序進行。

### 第 1 階段：完成教學並解鎖核心功能

- 完成新手教學與初期主線。
- 解鎖召喚、英雄管理、強化、覺醒等基本系統。
- 領取新手裝備與任務獎勵。
- 組成一支能自動或手動穩定通關的四人隊伍。

### 第 2 階段：優先推進主線與成長任務

- 按照遊戲目前的新手任務指引推進主線。
- 有新功能解鎖時，先花少量時間了解它的用途。
- 任務若要求通關特定章節、討伐或覺醒素材，優先完成能解鎖後續資源的項目。
- 不必一開始就把每個支線、每個成就全部清完。

### 第 3 階段：培養主力與免費英雄

- 從免費獲得的英雄中挑選能推圖、補血或破防的角色。
- 把主要資源集中在約 4～6 名核心英雄，不要同時平均養十幾隻。
- 先讓核心隊伍能通關目前進度，再投資第二支隊伍。

### 第 4 階段：開啟討伐與裝備農場

- 逐步挑戰討伐，先求成功率與穩定性。
- 先刷能穩定通關的難度，再慢慢提升。
- 優先取得能讓多數角色受益的裝備，而不是只追求單件最高分裝備。
- 當討伐隊伍穩定後，再把更多體力投入裝備與活動資源。

## 四、組隊觀念與角色職責

大部分 PvE 隊伍可從以下功能思考，而不是硬套固定角色表。

| 職責 | 主要工作 | 新手要注意什麼 |
|---|---|---|
| 坦克／騎士 | 承受傷害、保護隊友、提供減傷或控制 | 需要足夠生命、防禦；某些關卡還需要抗性或速度 |
| 補師／精靈師 | 治療、解除弱化、提供免疫或保護 | 先確保隊伍不容易倒下，再追求更快通關 |
| 輔助／破防手 | 提供攻擊增益、降低敵方防禦、施加弱化 | 命中與速度可能比攻擊力更重要 |
| 輸出手 | 對敵人造成主要傷害、清除小怪或擊殺首領 | 依技能選擇暴擊、暴傷、攻擊或速度等屬性 |

### 新手組隊的簡單範例

- **推圖隊**：一名能承傷的角色＋一名補師／輔助＋一至兩名輸出。
- **首領隊**：依首領機制帶破防、解除弱化、治療或特定屬性角色。
- **討伐隊**：依討伐首領的屬性、弱化要求及行動機制組隊。

不必強迫每隊都帶齊四種職責；若關卡需要快速擊殺或特定弱化，隊伍配置就應配合機制調整。

### 角色選擇的實用原則

1. 優先培養能在多個 PvE 玩法使用的角色。
2. 免費三星角色不代表沒用；部分角色可透過專職變更強化。
3. 不要只看排行榜。角色能否發揮，還取決於裝備、技能、隊友與關卡。
4. 角色技能描述中的「命中」、「抵抗」、「冷卻回合」、「速攻值」等關鍵詞要看懂。

## 五、角色培養順序

### 1. 升級與升星

- 先升級主力英雄，再依需求升星。
- 升星需要的材料與養成資源不少，先集中在核心輸出、主坦或關鍵輔助。
- 不要只因為角色是五星就立刻投入所有資源；先確認是否真的會用到。

### 2. 覺醒

覺醒通常需要元素祭壇等來源的素材。覺醒能提高能力或強化技能效果，建議先投資常用主力。

素材不足時，先完成能提升隊伍通關能力的覺醒，不必每隻角色都一次覺醒到滿。

### 3. 技能強化與摩拉戈拉

摩拉戈拉等技能強化資源取得有限，應審慎使用。

- 優先強化核心技能，尤其是能降低冷卻、提高關鍵效果或穩定破防的技能。
- 先閱讀技能升級前後的差異，再決定是否點滿。
- 新手期避免把珍貴資源平均灑在大量角色上。

### 4. 專職變更

部分三星英雄可以透過專職變更獲得新技能與能力提升。當任務或玩法解鎖專職變更時，查看所需任務，挑選能幫助主線、討伐或生存的角色優先完成。

### 5. 成長支援與英雄選擇券

如果遊戲提供成長支援、英雄選擇券或指定裝備套裝：

- 先選能補足隊伍缺口的角色。
- 確認是否能更換選擇，以及選擇券是否有期限。
- 若有成長支援系統，善用它降低前期養成成本，但仍要看清楚系統限制。

## 六、裝備與屬性入門

裝備是 E7 戰力的重要來源。新手不必一開始追求完美副屬性，先讓隊伍達到能通關的基本門檻。

### 1. 六個裝備位置

角色有武器、頭盔、盔甲、項鍊、戒指、鞋子六個位置。

- 左側三件（武器、頭盔、盔甲）的主屬性種類較固定。
- 右側三件（項鍊、戒指、鞋子）的主屬性選擇更重要，能大幅改變角色配裝方向。
- 右側裝備尤其要確認主屬性是否適合角色，不要只看裝備分數。

### 2. 常見屬性

| 屬性 | 常見用途 |
|---|---|
| 速度（SPD） | 影響行動順序；輔助、破防與許多輸出角色都可能需要 |
| 生命百分比（HP%） | 提高生命，常用於坦克與部分輔助 |
| 防禦百分比（DEF%） | 提高承傷能力，適合需要防禦的角色 |
| 攻擊百分比（ATK%） | 強化依攻擊力計算傷害的角色 |
| 暴擊率（Crit Chance） | 提高造成暴擊的機率 |
| 暴擊傷害（Crit Damage） | 提高暴擊時的傷害 |
| 效果命中（Effectiveness） | 幫助施加可被抵抗的弱化效果 |
| 效果抗性（Effect Resistance） | 幫助抵抗可被抵抗的弱化效果 |

**注意：** 效果命中不代表一定能施加弱化；部分技能有不可抵抗、固定機率或其他特殊規則。速度、命中、抗性等門檻也會因角色和敵人而不同。

### 3. 套裝與配裝

常見套裝效果包括速度、暴擊、命中、生命、防禦、抗性等。套裝是否值得穿，取決於角色技能和關卡需求。

新手可遵循：

- 輸出角色：先確保傷害屬性合理，並兼顧足夠速度與生存。
- 破防手：優先考慮速度、效果命中與生存。
- 坦克／補師：先達到足夠生命、防禦或抗性，再考慮速度。
- 不要為了湊套裝而穿上主屬性明顯不合適的裝備；初期可先使用屬性更好的散件。

### 4. 裝備強化策略

- 優先強化主力英雄正在使用的好裝備。
- 強化前先看主屬性與副屬性；不適合角色的裝備不要因為稀有度高就一直砸材料。
- 前期任務送的裝備可先用來推圖，之後再逐步替換。
- 不要急著把所有裝備升到滿級；先集中在核心隊伍。
- 不確定一件裝備值不值得留時，先保留並比較，不要急著賣掉或分解。

## 七、第一個長期目標：討伐與速度裝

討伐會提供裝備、製作材料等重要資源，是中長期養成的核心之一。不同討伐產出不同套裝，請在遊戲內查看當前掉落與製作內容。

### 1. 為什麼新手常先做冰龍討伐？

冰龍討伐（Wyvern）會提供速度、暴擊與命中等套裝方向的裝備。速度裝泛用性高，因此常被作為新手裝備農場的第一個長期目標。

但「先做冰龍」不代表所有帳號都必須使用完全相同的四人隊伍；請依目前版本贈送角色、帳號已有英雄及任務支援調整。

### 2. 組隊時要檢查什麼？

以冰龍為例，先確認：

- 能否穩定讓首領身上維持足夠的弱化效果（以當前首領機制為準）。
- 前排是否能活到戰鬥結束。
- 破防與主要弱化是否能穩定命中。
- 輸出是否足夠，能否在首領的關鍵階段前造成足夠傷害。
- 角色速度與行動順序是否互相配合。

### 3. 討伐難度怎麼選？

1. 先通關能穩定成功的難度。
2. 觀察失敗原因：前排倒下、弱化不足、傷害不夠或行動順序不對。
3. 每次只調整一至兩個問題，方便判斷改善效果。
4. 穩定後再往更高難度挑戰。

不要只追求最高難度的單次通關；長期刷裝時，**穩定性、速度與資源消耗**都值得考慮。

## 八、每日、每週與資源管理

### 每日登入建議

- [ ] 領取每日登入、信箱與當期活動獎勵。
- [ ] 查看每日任務與可領取的免費召喚（若當前活動提供）。
- [ ] 使用每日可取得的免費資源，避免過期。
- [ ] 收取聖域產出並檢查是否有可領取的養成材料。
- [ ] 完成公會捐獻、支援或其他日常項目（依功能解鎖情況）。
- [ ] 把體力優先用在當前最重要的主線、活動商店或討伐目標。

### 每週建議

- [ ] 檢查每週任務與商店刷新。
- [ ] 參與競技場，領取可取得的週獎勵。
- [ ] 參與公會內容，領取公會相關資源。
- [ ] 查看深淵、迷宮、塔類玩法或週期性 PvE 的進度。
- [ ] 整理裝備、英雄與背包，避免資源堆積卻沒有使用方向。

玩法開放條件及重置時間可能依版本調整，請以遊戲內倒數與說明為準。

### 資源優先順序

**體力**
- 新手推圖階段：優先解鎖重要系統並完成成長任務。
- 角色素材不足：針對主力刷覺醒素材或必要材料。
- 裝備不足：投入能穩定通關的討伐。
- 限時活動：比較活動商店獎勵與體力成本，優先換取稀有且難以取得的資源。

**天空石與召喚資源**
- 先確認限定召喚與保底需求。
- 不要因為一時想抽角色就花光所有資源。
- 留意神秘召喚、月光召喚等不同系統使用的貨幣與保底計數並不相同。

**金幣**
- 裝備強化、製作及商店等都可能消耗大量金幣。
- 避免反覆強化大量不會使用的裝備。
- 不要只因為副屬性看起來不錯，就把每件裝備都強化到底。

**摩拉戈拉、催化劑與稀有強化材料**
- 優先投資常用主力與關鍵技能。
- 升級前先確認素材用途與角色未來使用價值。
- 若素材能透過活動商店取得，請比較兌換優先度。

### 聖域（Sanctuary）

聖域是長期資源來源，記得定期收取並依帳號需求升級。常見功能包含靈魂森林、歐貝里斯之心及煉金術師之塔等；各功能用途與升級成本以遊戲內介面為準。

## 九、其他重要玩法

### 1. 深淵

深淵提供一次性或階段性獎勵，但部分樓層有特殊機制。遇到卡關時：

- 先閱讀首領技能與關卡限制。
- 確認是否需要解除弱化、驅散增益、破防、控制或特定屬性角色。
- 不要只靠堆戰力硬打；調整隊伍功能往往更有效。

### 2. 迷宮

迷宮需要注意路線、士氣或其他探索規則。新手先以拿取可取得的獎勵與解鎖後續內容為目標，不必一開始追求完美路線。

### 3. 競技場

新手可以先參與並完成週期任務，逐步累積獎勵。初期不必急著投入大量資源打造 PvP 專用隊伍；先把 PvE 基礎與裝備農場建立起來。

### 4. 公會

功能開放後，建議盡早加入活躍公會。公會通常能提供支援、任務、商店或其他長期資源。挑選能持續參與、規則適合自己的公會即可，不需要一開始就追求頂級公會。

### 5. 活動與支線故事

活動常提供養成素材、裝備、召喚資源或限定獎勵。活動開放期間請先確認：

- 活動期限與商店關閉時間。
- 需要通關哪些關卡才能取得主要獎勵。
- 哪些獎勵平常較難取得。
- 自己目前的隊伍是否能穩定刷取活動關卡。

不要把舊攻略中列出的活動角色、兌換碼或免費召喚次數當作永久存在；先查看官方公告與遊戲內活動頁面。

## 十、新手常見錯誤

1. **平均培養太多角色**：資源分散，結果每個角色都不夠強。先集中在核心隊伍。
2. **只看角色稀有度**：低稀有角色也可能是重要的破防、輔助或討伐成員。
3. **只追求高裝備分數**：主屬性、速度、命中與生存是否符合角色需求更重要。
4. **過早追求 PvP**：先把主線、討伐與常用 PvE 角色練起來，後續再發展競技場。
5. **亂花召喚資源**：抽卡前先了解保底、限定池期限與帳號缺少的角色功能。
6. **浪費技能強化資源**：摩拉戈拉等稀有資源應先投資核心技能。
7. **裝備強化沒有篩選**：先判斷裝備是否值得使用，再決定強化程度。
8. **忽略活動商店期限**：活動結束後可能無法再兌換，記得先確認倒數。
9. **照搬別人的隊伍**：角色、裝備和版本不同，隊伍不一定能直接複製。
10. **把一次失敗當成角色不行**：先檢查速度順序、弱化命中、坦度和首領機制。
11. **把所有資源囤著不使用**：資源要集中用在能推進帳號的核心隊伍，不必為了「完美時機」完全不養成。
12. **忘記查看遊戲內說明**：召喚保底、活動規則、商店兌換和系統開放條件都可能更新。

## 十一、第一個月進度表

這是彈性目標，不是必須照日期完成的硬性要求。若遇到卡關，先提升隊伍與裝備，不必為了趕進度硬推。

### 第 1～3 天：打好基礎

- [ ] 完成教學與新手召喚。
- [ ] 綁定帳號並領取信箱獎勵。
- [ ] 推進主線並解鎖基本功能。
- [ ] 選定約四名核心英雄。
- [ ] 穿上新手任務提供的合適裝備。
- [ ] 熟悉每日任務、活動與資源來源。

### 第 4～7 天：建立主力隊伍

- [ ] 持續推進主線與成長任務。
- [ ] 提升核心英雄等級、升星與必要覺醒。
- [ ] 開始挑戰可通關的祭壇、討伐等 PvE。
- [ ] 了解速度、暴擊、效果命中及生存屬性。
- [ ] 加入公會（若已解鎖）。
- [ ] 檢查稀有資源與召喚計畫。

### 第 2 週：提高通關穩定度

- [ ] 完成能取得關鍵角色、裝備或養成材料的任務。
- [ ] 找出討伐失敗的主要原因並逐項改善。
- [ ] 開始淘汰不適合主力的裝備。
- [ ] 推進深淵、迷宮與其他可取得獎勵的玩法。
- [ ] 持續參與限時活動，優先兌換重要資源。

### 第 3～4 週：建立長期農裝循環

- [ ] 讓一支討伐隊伍能穩定通關適合自己的難度。
- [ ] 逐步提升核心英雄裝備品質。
- [ ] 依實際需求補第二支隊伍或特殊關卡角色。
- [ ] 了解競技場、公會及週期玩法。
- [ ] 盤點天空石、書籤、神秘獎牌及稀有強化素材。
- [ ] 開始設定下一階段目標，而不是一次培養所有角色。

## 十二、出發前檢查清單

每次不知道該做什麼時，依序問自己：

1. 我今天的登入、信箱與活動獎勵領了嗎？
2. 我是否還有能解鎖重要功能的新手任務？
3. 我的主力隊伍目前卡在哪裡：等級、裝備、技能還是隊伍功能？
4. 我今天的體力最適合用在哪個目標？
5. 我是否準備好限定召喚所需的資源？
6. 我是否把稀有養成資源花在真正會使用的角色上？
7. 我是否有一支能穩定刷取裝備的隊伍？

如果以上大多數都已完成，就可以依帳號需要開始挑戰更高難度 PvE、改善裝備，或逐步投入 PvP。
